# 显存占用

考虑在不同的并行模式，不同的训练框架下，显存占用也会有所不同，例如使用megtron的时候，会开启分布式优化器。

## 1.TP并行

使用TP并行到N卡的时候，直接将模型的权重切分到N个卡上，模型参数，梯度，主权重，优化器状态全部除以N。

## 2. DP

当使用DP并行时，假设不使用分布式优化器，那么各个部分不会被切分，使用时等于zero1,会把优化器状态和主权重/N

## 3. EP

EP并行只切分EP部分的权重，其他部分全部切分

## 4. ETP

ETP在不设置的时候，默认跟随TP的配置，在EP切分的同时使用ETP继续进行切分

## 5. EDP

使用EDP的时候，不会对各类参数进行切分，假设使用分布式优化器，那么会对优化器状态和主权重进行切分
