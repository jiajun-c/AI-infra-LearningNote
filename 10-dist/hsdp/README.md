# HSDP 并行

FSDP 是将参数等切分到全部的CPU上，直到开始运行的时候去做一次allgather。其缺点是在跨机通信太慢。

所以HSDP将FSDP和DDP结合起来，其核心思想是将整个GPU集群划分成两个维度。

- 分片组：通常是一台机器(节点)内的8张卡，组内像FSDP一样，把模型参数，梯度，优化器状态分片存储
- 复制组：跨节点方向，每个节点保留了一份完整的分片后的模型副本，节点之间像DDP一样对梯度做all-reduce

## 1. 显存占用

单卡显存占用变成原先的1/8

## 2. 通信开销

高频的gather/scatter限制在节点内，跨节点只做低频的all-reduce，同时在通信的时候gather和scatter不可以和其他操作并行。而对梯度的all-reduce可以延后。
