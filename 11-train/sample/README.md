# 大模型sample

## 1. 背景

模型输出vocabulary logits

$z_1, z_2.. z_v$

经过 softmax 得到每个词的概率，然后从中按概率选择出一个元素

## 2. 算法实现

### 2.1 categorical sampling

最普通的实现是 `categorical sampling`，对p来求前缀和数组，然后生成一个随机数在`[0, 1]`之间，然后做二分查找看他落在哪个区间内，从而确定是选择哪个数据

数据复杂度`O(logn)`

### 2.2 alias method

假设有数组P，其大小为N，那么将所有的 $p_i$ 全部乘以N，得到一个新的数组。

然后我们创建N个桶，每个桶里面最多有两个元素，现在我们以1为界，分为两部分，然后每次从下数组和上数组选数据组成概率为1的，每次使用一个(1, N)均匀概率选出bucket，然后根据里面的概率选出里面的元素
